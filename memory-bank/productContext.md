# Product Context — Project_hand

## 为什么做这个项目

- 实现自动化抓取流程, 替代人工操作
- 统一多套相机 + 机器人 + 灵巧手的控制逻辑
- 在真实工业场景下验证视觉引导抓取的可靠性

## 解决的问题

1. **多相机兼容**: Camera A (RealSense D435i, 手动像素映射) + Camera B (UGREEN 1080P, 纯RGB OpenCV), 各自独立 pipeline
2. **复杂抓取目标**: 瓶身 (圆柱体)、把手 (不规则曲面)、水杯 (需定位杯口), 各自需要不同的检测策略
3. **位姿可靠性**: 通过 PoseStabilizer 多帧稳定 + 代际计数器防污染, 避免因检测抖动导致抓取失败
4. **分时调度**: 4 阶段顺序执行, 任何时刻只有一个检测器运行, 消除 GPU 竞争

## 用户场景

1. **双相机全流程**: 打招呼→抓壶倒水→抓杯递送→HandInCup判定→递出/放回, 4 阶段全自动
2. **把手抓取**: 烧水壶把手, YOLO kettle→HSV 青色贴纸→6D→旋转 band 补偿, 手指垂直插入
3. **水杯递送**: 倒水后抓杯递出, Camera B HandInCup 判定人是否接杯
4. **调试/标定**: 各模块有独立的测试脚本, 无需硬件即可验证算法链路
