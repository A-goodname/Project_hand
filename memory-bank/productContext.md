# Product Context — Project_hand

## 为什么做这个项目

- 实现自动化抓取流程, 替代人工操作
- 统一多套相机 + 机器人 + 灵巧手的控制逻辑
- 在真实工业场景下验证视觉引导抓取的可靠性

## 解决的问题

1. **多相机兼容**: 不同相机 (RealSense / EpicEye / Orbbec) 有不同的 SDK 和数据格式, 项目统一了检测接口
2. **复杂抓取目标**: 瓶身 (圆柱体)、把手 (不规则曲面)、水杯 (需定位杯口), 各自需要不同的检测策略
3. **位姿可靠性**: 通过 PoseStabilizer 多帧稳定 + 代际计数器防污染, 避免因检测抖动导致抓取失败
4. **灰度环境**: EpicEye 相机仅输出灰度图, 需要灰度 YOLO 模型

## 用户场景

1. **瓶身抓取**: 桌面上的水瓶, 机械臂抓取后抬起放置到目标位置
2. **把手抓取**: 烧水壶把手, 需要精确定位把手位置和朝向, 手指垂直插入
3. **水杯抓取**: 倒水场景, 先抓把手倒水, 再抓水杯递出
4. **调试/标定**: 各模块有独立的 Demo 脚本, 无需硬件即可验证算法链路
