=== 协议总览 ===
Phase A: Robot → PC  [x,y,z,A,B,C]       初始末端位姿
Phase B: PC → Robot  <H_P1>[H_P2]{H_P3}   Handle 三组位姿
Phase C: 指令循环: PREGRIP → GRIPDONE → RESET → CUP
         PC → Robot  <C_P1>[C_P2]{P3}    Cup 位姿 (P3=递送)
         灵巧手: RELEASE(松把手, hand_in_cup_active=False) → GRIP(抓杯)
Phase D: READY → (PC 启动 HandInCup, hand_in_cup_active=True) → Wait 2s → RELEASE
         PC 根据 HandInCup 判定结果发送 CONTINUE 或 ABORT
         PC → Robot  CONTINUE(<0,0,0,0,0,0>) / ABORT([0,0,0,0,0,0])   ← 无换行, 括号定界
         TRUE:  (松手) P4 退避 → RESET → Home → SocketClose
         FALSE: (不松) P1 放回 → RELEASE(放回后松杯) → P2 退避 → RESET → Home → SocketClose

=== 信号变量 ===
  str1 = "PREGRIP"    — 预抓取 (Handle 用)
  str2 = "GRIPDONE"   — 抓取完成 (Handle 用)
  str3 = "RESET"      — 手复位
  str4 = "CUP"        — 请求 Cup 位姿
  str5 = "RELEASE"    — 双语义: READY之前→松把手 / READY之后→HandInCup判定触发
  str6 = "GRIP"       — 夹紧 (抓杯)
  str7 = "READY"      — [v4] 到达 P3, 启动 HandInCup 检测 (PC: hand_in_cup_active=True)

PC 端 RELEASE 处理逻辑 (state_machine.py):
  hand_in_cup_active == False → release_object() 松把手 (Phase C)
  hand_in_cup_active == True  → HandInCup 判定 → CONTINUE/ABORT (Phase D)
  ABORT 路径第二次 RELEASE    → release_object() 放回后松杯

响应字符串:
  CONTINUE = "<0,0,0,0,0,0>"  — [v4] PC→Robot, HandInCup=TRUE,  松手退避 (<> 定界)
  ABORT    = "[0,0,0,0,0,0]"  — [v4] PC→Robot, HandInCup=FALSE, 放回杯子 ([] 定界)

=== 位姿标记 ===
  Handle: H_P1 <...>, H_P2 [...], H_P3 {...}, H_P4 (计算)
  Cup:    C_P1 <...>, C_P2 [...], C_P3 {...}, C_P4 (计算)

=== 路径 ===
  Handle: H_P2 → H_P1 → H_P4 → H_P3 → H_P4 → H_P1 → H_P2 → Home
  Cup(TRUE):   C_P2 → C_P1 → GRIP → C_P5 → C_P3 → READY+RELEASE+CONTINUE → C_P4 → Home
  Cup(FALSE):  C_P2 → C_P1 → GRIP → C_P5 → C_P3 → READY+RELEASE+ABORT → C_P5 → C_P1 → C_P2 → Home
  C_P5 = CposOffset(C_P1, DCp3), DCp3.dz=100mm (P1 Z+10cm, 防碰撞)

SocketSendStr(Socket0, 'READY')          // → PC: 到达递送点, 启动 HandInCup (hand_in_cup_active=True)
Wait 2s                         // 留给 PC 运行 HandInCup 检测的时间 (给人抓杯+检测稳定时间)

// --- [6b] 发送 RELEASE → PC 判定 ---
SocketSendStr(Socket0, 'RELEASE')        // → PC: 请求判定 HandInCup

// --- [6c] 等待 PC 返回 CONTINUE 或 ABORT ---
// PC 端响应格式:
//   CONTINUE → "<0,0,0,0,0,0>"  (用 < > 标记, TranStrToCpos 成功 → flag_cont=0)
//   ABORT    → "[0,0,0,0,0,0]"  (用 [ ] 标记, TranStrToCpos 成功 → flag_abort=0)
// 注意: 两个 TranStrToCpos 都从同一个 socketstr5 解析, 只有一个会成功.
strflag_cont = 1   // 初始=1 (失败)
strflag_abort = 1  // 初始=1 (失败)
strflag = 1
while strflag == 1
    SocketReadStr(Socket0, socketstr5, 5000, socketflag, "", "")
    if socketflag == 0
        // 尝试解析 <...> 格式 (CONTINUE 标记)
        DummyCpos = TranStrToCpos(socketstr5, ",", DummyCpos, strflag_cont, "<", ">", "deg", "m")
        // 尝试解析 [...] 格式 (ABORT 标记)
        DummyCpos = TranStrToCpos(socketstr5, ",", DummyCpos, strflag_abort, "[", "]", "deg", "m")
        strflag = 0
    Wait 500ms

// ================================================================
// [7] 分支处理: CONTINUE vs ABORT
// ================================================================

// --- 计算 Cup P4 安全退避点 (C_P1.XY + C_P3.Z + C_P1.ABC) ---
DCp2.dz = 100                   // v11: 固定 10cm 安全退避高度
C_P4 = CposOffset(C_P3, DCp2)     // P4 = P3 位姿 + Z偏移 (Home高度)

// --- [7a] CONTINUE 分支: 有人接杯 → 松手已由 PC 执行 → 退避 ---
// 注: 当 PC 发送 CONTINUE 时, PC 已调用 release_object() 松手
// 机械臂只需安全退避即可
if strflag_cont == 0
    MovL C_P4                   // → 安全退避点 (上升到递送高度)
    Wait 1s
    SocketSendStr(Socket0, 'RESET')      // → PC: 灵巧手 RESET
    Wait 1s
    MovL Home                   // → 回原点
    SocketClose(Socket0)
endif

// --- [7b] ABORT 分支: 无人接杯 → 保持夹紧 → 放回原位 ---
// 注: 当 PC 发送 ABORT 时, PC 未调用 release_object()
// 机械臂带着杯子放回原位再松手
// v10: 先经 C_P5 安全高度再回 C_P1, 避免碰撞桌子
if strflag_abort == 0
    // 注意: 此时灵巧手仍然夹着杯子 (PC 端未松手)
    MovL C_P5                   // → 安全高度点 (v10 新增)
    Wait 1s
    MovL C_P1                   // → 回到抓取点 (放回水杯)
    Wait 1s
    SocketSendStr(Socket0, 'RELEASE')    // → PC: 灵巧手 RELEASE (松杯) — 第二次 RELEASE
    Wait 1s
    MovL C_P2                   // → 回到预抓取点 (安全退避)
    Wait 1s
    SocketSendStr(Socket0, 'RESET')      // → PC: 灵巧手 RESET
    Wait 1s
    MovL Home                   // → 回原点
    SocketClose(Socket0)
endif
