### 1. 眼在手上 (Eye-in-Hand) -- 当前已实现

- 相机: RealSense D435i (安装在机械臂末端)
- 功能:
  - 检测水壶把手位置, 计算 6D 位姿
  - 控制机械臂 + 灵巧手完成抓取把手 → 倒水动作
  - 检测水杯位置, 抓取水杯
- 状态: ✅ 把手抓取流程初步跑通 (右侧), 水杯检测待开发

### 2. 眼在手外 (Eye-to-Hand) -- 待实现

- 相机: 固定安装在上方或侧方 (独立于机械臂)
- 功能:
  - 检测人的位置 (人体检测/人脸朝向/骨架)
  - 识别人的手势, 判断是否松手 (open palm = 松手)
  - 控制机械臂将水杯递送到人手中
  - 作为整个系统的启动触发器 (检测到人 → 开启全流程)
- 状态: ❌ 未开始

## 详细开发计划

### Phase 1: 完善眼在手上 (当前阶段)

- [ ] **左把手抓取标定与测试**: `fixed_abc.left` 配置已预留, 需补充标定数据后验证
- [ ] **抓取姿态贴合度优化**: 微调 `pre_offset` / `target_offset` 参数改善灵巧手与把手的贴合度
- [ ] **机械臂通信超时调整**: 2s → 5s, 减少超时断连
- [ ] **水杯检测与抓取**: 扩展 YOLO 模型识别水杯, 计算 6D 位姿, 实现抓取水杯
- [ ] **倒水流程实现**: 抓取把手 → 移动至水杯上方 → 倾倒 → 回正

### Phase 2: 搭建眼在手外

- [ ] **硬件选型与安装**: 选择适用于人体检测的相机 (RGB-D, 如 RealSense / Orbbec / 普通 RGB 相机), 固定安装在机械臂工作空间外
- [ ] **人体检测模块**: 使用 YOLOv8 人体检测或 MediaPipe 骨架检测, 识别人体位置与朝向
- [ ] **手势识别模块**: 检测人手开合状态 (open/close), 作为松手信号
- [ ] **眼在手外标定**: 标定外置相机到机器人基坐标系的变换矩阵
- [ ] **防碰撞路径规划**: 机械臂在眼在手外视野内运动时的安全避障

### Phase 3: 双相机融合

- [ ] **流程编排**: 眼在手上完成后通知眼在手外, 启动递送流程
- [ ] **状态机管理**: 空闲 → 倒水 → 递送 → 等待 → 松手 → 复位
- [ ] **异常处理**: 人手移开/物体滑落/检测失败等情况下的恢复策略

## 眼在手外模块设计草案

### 检测目标

| 目标 | 方法 | 说明 |
|------|------|------|
| 人体位置 | YOLOv8 person class / MediaPipe Pose | 获取人体中心在机器人基系下的 3D 位置 |
| 手部位置 | MediaPipe Hands / YOLOv8 hand class | 获取手部 3D 位置, 作为递送目标点 |
| 手势判断 | MediaPipe Hand Landmarks | 根据手指弯曲度判断 open/close |
| 人脸朝向 | MediaPipe Face / head pose estimation | 判断人是否面向机器人 (可选) |

### 坐标系转换

```
眼在手外相机系 ──标定──→ 机器人基坐标系
                            ↓
人体/手部位置在基系下的 3D 坐标 → 机械臂运动目标
```

### 触发逻辑

1. 眼在手外检测到人进入工作区域 → 发送信号启动眼在手上流程
2. 眼在手上完成倒水并抓取水杯 → 通知眼在手外
3. 眼在手外计算人手位置 → 发送递送目标给机械臂
4. 机械臂移动到人手附近 → 眼在手外持续检测手势
5. 检测到 open palm → 发送 RESET (松手) → 机械臂退回安全位置
