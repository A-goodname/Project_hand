## 1. 完成把手抓取流程初步跑通

- 整合 RealSense D435i 视觉检测 + ESTUN 机械臂控制 + 灵巧手抓取
- 检测流程: 微调 YOLOv8n 检测把手 → SAM2 分割 → 扫描线分离 → 6D 位姿估计
- 抓取流程: 稳定位姿 → P2(预抓取) → PREGRIP → P1(抓取) → GRIPDONE → P3(目标)
- 对不同位置的水壶均能实现把手稳定检测与抓取

## 2. 抓取姿态贴合度

- **当前状态**: 抓取姿态没有完全贴合把手, 存在一定倾斜
- 但灵巧手能够抓稳把手, 不影响实际抓取功能
- 后续可通过微调 `pre_offset` / `target_offset` 参数改善贴合度

## 关键设计决策记录

### 扫描线分离算法 (scanline_find_handle)

| 版本 | 策略 | 说明 |
|------|------|------|
| 初始 | 面积较小段 = 把手 | 简单但容易误判, 当把手面积接近壶身时失效 |
| v2 (c3a7913) | 按 handle_side 取最外段 | "right" 取最右段, "left" 取最左段, 更鲁棒 |

### X 中心一致性过滤 (handle_center_deviation_ratio)

| 版本 | 策略 | 说明 |
|------|------|------|
| 初始 | 仅底部向上剔除 | 解决 C 形把手底座误检, 但对顶部偏离行无效 |
| v2 (c3a7913) | 底部+顶部 双向剔除 | 从底部向上 + 顶部向下同时剔除偏离行, 更彻底 |

### 偏移参考系变更 (24e26ba)

- **before**: `pre_offset` / `target_offset` 在当前末端系 (current ee frame) 下定义, 未考虑抓取姿态旋转
- **after**: 偏移量在抓取点末端系 (grasp ee frame) 下定义, 左乘 `R_grasp_ee` 转换到当前末端系
- **影响**: P2/P3 在基系下的偏移分量与配置在 grasp ee frame 下的方向一致

### 稳定逻辑修正 (e347717)

- **before**: `PoseStabilizer.add()` 每帧都执行, 导致稳定后的位姿混合了跳帧间的零值/旧值, 产生虚假稳定
- **after**: `stabilizer.add()` 仅检测帧执行, 在相机系稳定后做一次 `cam→ee` 转换, 避免跨帧污染

### 红色胶带辅助检测 (68b7526)

- 在把手上贴红色胶带, 通过 HSV 色彩检测获取精准位置
- 红色位置替换 `handle_pos` (3D 位置), 旋转保持 PCA 输出不变
- 通过 `RealSense_R/config.yaml` 中 `red_tape` 段控制:
  - `enabled`: 总开关 (true/false)
  - `min_area`: 红色区域最小有效面积 (像素)
- `detect_red_tape()` 函数使用中位数计算中心, 比均值更鲁棒

### orientation_mode 更新 (e347717 / e053fd8)

| 模式 | 状态 | 说明 |
|------|------|------|
| `free` | ✅ | 跟随物体朝向, Y 轴统一后 `R_obj_ee @ Rz(+90)` |
| `vertical` | ✅ | 末端 Z 轴水平约束, 从侧面抓取竖直水瓶 |
| `fixed` | ✅ (新增) | P1/P2 使用 `fixed_abc` 固定姿态, P3 叠加旋转 |
| `horizontal` | ❌ | 暂未实现 |

- **C 值约束**: vertical/free 模式下 P1 的 C 角固定到 `[-100, -80]`, 使手指垂直于把手
- `fixed_abc` 左右手独立配置 (`Estun/estun_config.yaml`)
