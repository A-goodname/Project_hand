# 把手抓取项目进展记录

## 上次更新: 2026-06-09

---

## 1. 完成把手抓取流程初步跑通

- 整合 RealSense D435i 视觉检测 + ESTUN 机械臂控制 + 灵巧手抓取
- 检测流程: 微调 YOLOv8n 检测把手 → SAM 分割 → 扫描线分离 → 6D 位姿估计
- 抓取流程: 稳定位姿 → P2(预抓取) → PREGRIP → P1(抓取) → GRIPDONE → P3(目标)
- 对不同位置的水壶均能实现把手稳定检测与抓取

## 2. 抓取姿态贴合度

- **当前状态**: 抓取姿态没有完全贴合把手, 存在一定倾斜
- 但灵巧手能够抓稳把手, 不影响实际抓取功能
- 后续可通过微调 `pre_offset` / `target_offset` 参数改善贴合度

## 3. 抓取方向支持

| 方向 | 状态 | 说明 |
|------|------|------|
| 右手 (`right`) | ✅ 已实现 | 掌心向左, 已完成测试与验证 |
| 左手 (`left`)  | ❌ 部分配置 | `estun_config.yaml` 中 `fixed_abc.left` 已预留配置位, 但未完成标定与测试 |

- `grasp_direction` 配置项已支持切换, `fixed_abc` 段已预留左右手独立配置
- 左手抓取需要补充标定 `fixed_abc` 数据后进行验证

## 4. 机械臂端通信

- **问题**: 连接后多次出现通信超时
- **原因**: ESTUN `SocketReadStr` 的通信超时默认值为 2s
- **处理**: 建议将超时改为 5s (已记录, 未实际测试验证)
- 通信协议已改为合并一次发送 P1/P2/P3 三个位姿, 协议格式验证通过
